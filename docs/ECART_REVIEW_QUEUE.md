# ÉCART review queue

The queue is an explicit, unit-testable rule set. It uses `未確認`, `要確認候補`, `情報不足`, `確認優先度`, `最終観測`, and `確認根拠`; it never determines a person to be missing, harmed, or deceased, and it never dispatches anyone. In-person or shelter check-in is confirmed; third-party or device-only information remains a review candidate. Mobility or power support combined with no current observation is high priority. Staff changes are visibly marked as manual and audited.
