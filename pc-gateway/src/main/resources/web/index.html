Relay PC Gateway

中継拠点コンソール

zero-operation 運用 一般端末の登録は不要です。Android は UDP ビーコンで本機を発見し、公開同期で REPORT を送ります。 公開経路・ペアリング済み経路のどちらでも、REPORT本文と発信元は CONTENT UNVERIFIED（内容未検証） です。ペアリングはBridge経路だけを認証し、 公式情報・本人確認・最終宛先への配信を意味しません。
